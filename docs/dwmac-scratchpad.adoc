// =========================================================== Description
== Description

// tag::body[]
{manpurpose}
The behavior is similar to Xmonad's NamedScratchpad.

A scratchpad is declared in the config and owns all windows of one app:

[source,toml]
----
[scratchpad.signal]
app-id = 'org.whispersystems.signal-desktop'
width = 0.9  # fraction of the monitor's visible area. Optional, 0.9 by default
height = 0.9 # Optional, 0.9 by default
----

Windows of the app never join regular workspaces.
When they appear, they go straight to a hidden workspace that belongs to the scratchpad
(`on-window-detected` callbacks are not run for them).

The command:

* summons the scratchpad windows to the focused workspace as floating windows, centered and sized
  according to `width` and `height`, and focuses them, if the scratchpad isn't on the focused workspace
* focuses the scratchpad, if it's on the focused workspace but isn't focused
* sends the scratchpad back to its hidden workspace, if it's focused
* launches the app and summons its first window once it appears, if the app has no windows

A summoned scratchpad is only visible while it's focused.
As soon as focus moves to a window of another app, the scratchpad is sent back to its hidden workspace.
